# Harper Adams styling

This personal PIA fork uses navy `#012169` and yellow `#FFE800`, taken from the university website’s `.harper-blue` and `.harper-yellow` rules. Pale blue and neutral surfaces are supporting UI colours. Status colours remain distinct.

The unmodified white SVG logo is sourced from https://www.harper-adams.ac.uk/img/brand/white/HAU-logo.svg and displayed on navy with its original proportions. Palette source: https://www.harper-adams.ac.uk/v2/css/page.css (retrieved 4 November 2026). The logo remains the university’s artwork, rather than part of the project’s MIT-licensed code. This personal workspace does not imply institutional endorsement.

The theme covers workspace navigation, task controls, editors, assistant setup and server-rendered sign-in pages. Assets are served locally in both the private app and the browser demo; no runtime request to the university is required.
